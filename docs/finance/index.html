5. Where should site 28 go?

Volume for each location is predicted from traffic, competitors and local income, using what the 24 established sites actually do. Move the sliders to test the decision.

Value created over 10 years (NPV)

Dot: with the slider settings. Bar: if volume comes in low or high (about a 4 in 5 chance it lands inside).

How to read it: profit is before head-office cost, interest, tax and depreciation. NPV is future cash discounted back to today, minus the build cost; above zero means the project beats the required return. IRR is the yearly return the project earns.
